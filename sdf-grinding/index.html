Core operation

Subtract the tool

The workpiece and wheel are both signed distance fields. Removing wheel volume is one pointwise CSG operation:

φnew(x) = max(φold(x), −φtool(T−1x))

The same edited texture is sampled by hydroelastic collision and converted to a visible mesh every frame.

SDF–SDF contact

Four pieces are enough

Newton’s hydroelastic path samples each shape’s texture SDF and constructs the pressure-equilibrium contact surface. A solver is optional: collision generation can be invoked directly.

Collide explicitly

Move the kinematic wheel, update body transforms, then call pipeline.collide().

cfg = newton.ModelBuilder.ShapeConfig(
    is_hydroelastic=True, kh=1.0e8, gap=0.005, margin=0.0
)

workpiece_mesh.build_sdf(max_resolution=256, paired_samples=False)
builder.add_shape_mesh(body=-1, mesh=workpiece_mesh, cfg=cfg)

tool_cfg = cfg.copy()
tool_cfg.sdf_max_resolution = 64
builder.add_shape_cylinder(
    body=tool_body, radius=0.13, half_height=0.04, cfg=tool_cfg
)

pipeline = newton.CollisionPipeline(
    model,
    sdf_hydroelastic_config=newton.geometry.HydroelasticSDF.Config(
        output_contact_surface=True
    ),
)
pipeline.collide(state, pipeline.contacts())

Grinder loop

Contact, carve, refresh

The example keeps writable arrays for Newton’s coarse and packed fine SDF textures. Every step measures contact pressure, applies the CSG difference, uploads the changed samples to the same texture handles, and extracts the zero isosurface with Marching Cubes for ViewerGL. 

pipeline.collide(state, contacts)          # pressure on the current surface
subtract_grinder(coarse, fine, tool_pose)  # max(workpiece, -tool)
coarse_texture.copy_from(coarse)
subgrid_texture.copy_from(fine)

surface = workpiece_sdf.extract_isomesh()  # Marching Cubes, isovalue = 0
viewer.log_mesh(
    "/workpiece_sdf", points, indices, dynamic=True
)

Run it

No Newton patch required

Download the file, then run it from any current Newton source checkout with the examples extra installed. 

cd <newton-checkout>
uv sync --extra examples
uv run python <path-to-download>/example_sdf_grinding.py

The demo intentionally performs geometric removal only. A physical grinder can add a solver, use pressure and slip speed to determine wear rate, and move only that incremental material volume out of the SDF each step.
