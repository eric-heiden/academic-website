Cartpole Fix

The first cartpole run loaded the DiffRL URDF directly into a Y-up Newton model. DiffRL actually applies a -pi/2 rotation about X before setting the pole joint to -pi. Without that transform, gravity and the pole axis were mismatched, producing the sideways-looking behavior. The Newton harness now applies the same transform.

Ant Diagnosis

The ant MJCF import was missing an explicit ground plane, so both contact backends initially let the ant fall through the world. The ant builder now uses DiffRL's Y-up transform, rest pose, contact material, previous-action observation, early termination, and a Y-up ground plane. The qfrc_bias/cfrc_int RNE gradient path is now fixed for the reduced two-link gravity scene. The remaining Ant failure is not a contact-backend choice: Newton, MuJoCo, and no-contact checks all show accurate one-step action gradients but bad multi-step state gradients, especially root quaternion and root velocity sensitivities.

Root Cause Drilldown

The isolated zero-gravity, zero-velocity, forced two-link scene has no contacts, no gravity, and no Coriolis term. Its only q sensitivity is the mass-matrix solve qacc = M(q)^-1 f. That path matches finite differences after adding the dense mass-solve VJP and rewriting dense off-diagonal M assembly. The gravity-only two-link error is also fixed after adding a custom RNE VJP for qfrc_bias/cfrc_int. The raw direct vec10 probe still produces zero gradients, so solver paths that read cinert need explicit VJPs.

MJWarp Code Findings

The first fix was straightforward: fwd_acceleration propagated qacc_smooth.grad to qfrc_smooth.grad but did not propagate the solve VJP into M.grad. Adding that exposed a second bug in dense _M_dense: off-diagonal entries were numerically correct forward but their generated adjoints were zero. A pairwise dense kernel fixes the zero-gravity forced two-link case. The next bug was the raw vec10 inertia path: fixed-weight cinert reads still have zero adjoints. The RNE path now bypasses that with a custom qfrc_bias.grad -> cfrc_int.grad -> cinert VJP -> xipos/ximat/subtree_com callback. An experimental dense mass/crb VJP overcorrected the reduced mass probe and was backed out; that is the next code path to derive carefully.

Implementation Notes

Newton's SolverMuJoCo uses the MJWarp differentiability branch with opt-in gradient-enabled data fields. The harness wraps one Newton/MJWarp step in a PyTorch autograd function: forward runs the solver normally, backward replays the step under a Warp tape and returns MJWarp adjoints to PyTorch.

Status

Cartpole is physically plausible and stabilizes. Ant now has correct ground contact and accurate one-step action gradients. The reduced RNE gravity scenes are fixed by a custom qfrc_bias/cfrc_int VJP that bypasses raw vec10 autodiff. Full SHAC Ant remains blocked by state Jacobian errors that persist with contacts disabled, pointing next at free-body quaternion/velocity and composite-inertia mass-matrix derivatives.
