SHAC with MuJoCo Warp

Newton experiments coupling SHAC-style differentiable policy optimization to the MuJoCo Warp differentiability branch. The latest pass stages the problem through acrobot target control, free-body control, sphere/capsule contact targets, Hopper, Cheetah, and Ant. The newest MJWarp fix removes duplicate auto-AD through the RNE qfrc_bias/cfrc_int path, so free-fall mass/bias VJPs cancel correctly and Hopper/Ant one-step state gradients match finite differences again. Cheetah now works as a staged SHAC target: Newton contacts move 7.57 m in the latest 8 s rollout, and MuJoCo contacts move 5.40 m when rollout state is reset each epoch. Hopper and Ant still need training stabilization: their short-horizon gradients are now clean, but contact-rich SHAC optimization still collapses or plateaus before reliable locomotion.

What Is Fixed

The MJWarp gradient path now includes fixes for free-joint kinematics replay, dense mass-solve VJPs, RNE qfrc_bias/cfrc_int adjoints, in-place state output isolation in _advance, and repeated root writes in com_vel. This update adds active contact-row aref/D VJPs, contact-row position gradients for all pyramidal rows, contact buffer isolation, and the missing quadratic-row efc.J force-law term. The latest fix computes differentiable kinematics once per body level instead of replaying body_branches; this removes the duplicated root-pitch gradient in branched planar bodies and drops Cheetah no-contact state/action error to 6.4e-5. The newest cinert adjoint hook improves Ant H=2 policy finite differences from 3.5e-1 to 1.3e-1 and Cheetah/MuJoCo policy finite differences to 1.1e-2. The newest RNE fix replaces auto-backward through qfrc_bias with an explicit adjoint and disables auto-backward through the cfrc tree accumulation; Hopper no-limit smooth dynamics now has 2.7e-4 full state/action error and Ant H=5 one-step state/action error is 8.1e-5.

What Is Not Fixed

Contact-rich training is still not solved for Hopper or Ant. Hopper with joint limits has nonsmooth finite differences at the reset pose because the thigh and leg start exactly on their upper limits; disabling those limits makes smooth state/action gradients pass, but training folds into invalid low postures. Ant one-step state/action gradients now pass through H=5, but a 64-env SHAC run improved only to roughly 1.5 mean reward before declining, so reliable Ant locomotion still needs contact/optimization stabilization rather than another smooth-dynamics VJP fix.

Code Findings

The most important MJWarp fixes were not contact-specific. First, free-joint kinematics were recomputed once per branch, corrupting qpos gradients for floating roots. Second, dense mass assembly had no useful generated adjoint for the dense matrix path used by the solve. Third, RNE force accumulation needed explicit adjoints for cfrc_int, cinert, cdof, and related kinematic intermediates. Fourth, _advance had to isolate output qpos/qvel arrays under AD to avoid overwriting saved inputs. Fifth, Newton's free-joint force route writes to MJWarp xfrc_applied; the support.apply_ft map into qfrc_smooth needed an explicit VJP for free-root force controls. The latest Hopper free-fall drilldown showed the key cancellation bug: CPU MuJoCo and MJWarp both produce pose-independent free-fall acceleration, but AD still injected root-angle and joint-position gradients. Finite-difference decomposition showed the dense M VJP was correct; the residual came from leaving Warp auto-AD active through qfrc_bias = dot(cdof, cfrc) and the cfrc tree accumulation while also recording the custom RNE adjoint. The fix disables those auto-backward kernels and records an explicit qfrc_bias adjoint that routes cdof.grad and cfrc_total.grad exactly once.

SHAC Findings

The harness had its own bug: early terminal falls still bootstrapped from the critic. DiffRL sets the terminal value to zero for early termination. Matching that behavior, and making terminal fall reward a fixed negative value, removes the high-speed crash exploit. The new upright gate also rejects the rolled-over progress policy. The remaining failure is no longer a simple smooth-dynamics gradient bug: Hopper and Ant short-horizon state/action checks now pass, but SHAC training still trades progress against repeated contacts and active limits poorly. Hopper with limits on is nonsmooth at reset because the thigh and leg joints start on their upper stops; no-limit Hopper verifies the smooth dynamics but folds during training. Ant H=5 state/action gradients now match finite differences, yet the latest 64-env SHAC run plateaued near 1.5 reward and then declined. The next bug hunt should target contact/limit training stability and policy-gradient variance, not the RNE mass/bias cancellation.
