SHAC with MuJoCo Warp

Newton experiments coupling SHAC-style differentiable policy optimization to the MuJoCo Warp differentiability branch. The current report uses full-horizon checkpoint selection for locomotion, raw ViewerGL.get_frame() videos through one shared smoothed COM follow camera, and a new uninterrupted no-reset evaluator so terminal states are not hidden by reset-spliced metrics. PPO now saves/loads critic checkpoints for valid continuation, and PPO actors are no longer double-squashed during shared evaluation. The latest Ant reruns also fix the native action_squash=none path: PPO and SHAC actions are now clamped to [-1, 1] before the Newton force map, matching DiffRL and IsaacLab actuator semantics instead of allowing out-of-range torques. The clean PPO baselines verify the Newton/MJWarp task setups: Hopper reaches 14.51 m with 0 no-reset terminals, Cheetah reaches 12.66 m with 0 no-reset terminals, and the corrected clipped IsaacLab-potential Ant PPO replay reaches 15.18 m with 0 terminal worlds across five 1024-world no-reset repeats. The previous 30 m-class native no-squash Ant traces are kept below as diagnostics, but they are no longer treated as valid baselines because they relied on unclipped actions. A reward-bookkeeping bug in the Ant potential-progress path is fixed here: q_next - q is now divided by the full control timestep, not the physics substep. Cheetah is the clean SHAC stepping stone: MuJoCo contacts at substep 1 reach 10.41 m uninterrupted with 0 terminals. Hopper SHAC is now clean after moving the deterministic start pose off exact active joint limits and using a reliability-scale 1024-world selector: it reaches 13.65 m uninterrupted with 0 terminals. Ant SHAC now preserves the clipped PPO anchor, and a cautious H=8 update improves the deterministic no-reset replay to 15.39 m with 0 terminals. Five repeated no-reset audits still expose the open reliability target: PPO has 0 terminals and minimum-up above 0.945, while the H=8 SHAC update has 0 terminals but one repeat dips to 0.485 minimum-up before recovering. Longer H=16/H=32 Ant SHAC updates remain too slow or contact-sensitive to call reliable. The MJWarp branch used here includes the fixes from this investigation: free-joint kinematics replay, dense constrained mass-solve VJPs, explicit RNE qfrc_bias/cfrc_int adjoints, branch-level kinematics replay, contact row aref/D/J adjoints, control buffer isolation, and Newton MJCF per-DOF joint-anchor preservation. Reset-state one-step gradients are now clean; the remaining gradient mismatch appears in multi-step grazing contacts, especially Ant foot contacts over H=8/H=16 horizons.

What Is Fixed

The MJWarp gradient path now includes fixes for free-joint kinematics replay, dense mass-solve VJPs, RNE qfrc_bias/cfrc_int adjoints, in-place state output isolation in _advance, and repeated root writes in com_vel. This update adds active contact-row aref/D VJPs, contact-row position gradients for all pyramidal rows, contact buffer isolation, and the missing quadratic-row efc.J force-law term. The latest fix computes differentiable kinematics once per body level instead of replaying body_branches; this removes the duplicated root-pitch gradient in branched planar bodies and drops Cheetah no-contact state/action error to 6.4e-5. The newest cinert adjoint hook improves Ant H=2 policy finite differences from 3.5e-1 to 1.3e-1 and Cheetah/MuJoCo policy finite differences to 1.1e-2. The newest RNE fix replaces auto-backward through qfrc_bias with an explicit adjoint and disables auto-backward through the cfrc tree accumulation; Hopper no-limit smooth dynamics now has 2.7e-4 full state/action error and Ant H=5 one-step state/action error is 8.1e-5. On the harness side, Newton-contact vectorized environments now use nonzero world spacing, PPO checkpoints can warm-start SHAC actors, Ant actions can follow either IsaacLab-like joint order or MuJoCo actuator order, the Isaac-style Ant height reward now uses ant_height_weight, checkpoint selection can include forward displacement, initial PPO warm starts are evaluated and saved before any SHAC update, and SHAC selection can now run on a separate large randomized environment batch via --selection-num-envs. The PPO runner now mirrors that safeguard for loaded actors by evaluating and saving update 0 before any PPO fine-tune step. SHAC can also use a no-LayerNorm actor architecture that exactly matches PPO checkpoints. Shared policy evaluation now preserves explicit action semantics: SHAC actors output raw pre-tanh actions when configured with action_squash=tanh, while PPO actors with action_squash=none are evaluated without an accidental second tanh. SHAC can now regularize updates against a frozen reference policy using an optional action-space anchor penalty, which makes the new Ant speed probes reproducible rather than one-off checkpoint edits. Ant selection thresholds now use recorded minima such as min_up and min_height instead of batch means, so rare inverted worlds are penalized instead of hidden by high average uprightness. Training warmup rollouts now run under torch.no_grad() and detach their returned state, so late-state probes initialize the differentiable horizon without accidentally backpropagating through hundreds of warmup steps. The newest Ant harness fix uses the stable -90 degree X free-root start quaternion for both DiffRL and NV Ant imports, because this is the pose that matches the configured start joints after Newton exports to the MuJoCo/MJWarp runtime. It also drops the embedded NV floor before adding Newton's ground plane; this removes the duplicate coplanar floor contacts while preserving the native NV 0.01 hinge armature. The newest Ant runner fix clamps all policy actions before force assignment, so native no-squash PPO and SHAC now use the same bounded action contract as DiffRL and IsaacLab. A direct velocity probe also verified that the imported Ant root convention is linear velocity in qd[0:3] and angular velocity in qd[3:6]; the remaining Ant issue is not a swapped velocity observation. The shared report renderer now follows a smoothed mass-weighted COM target and no longer resets videos on falls, so visible rollouts show the actual policy trajectory rather than a reset-spliced episode. Hopper stochastic resets are clamped inside finite joint limits. The newest Newton fix preserves MJCF joint anchor positions per expanded DOF; this fixes Hopper's root slide/hinge anchors when SolverMuJoCo exports merged Newton joints back to MuJoCo and when it refreshes the MJWarp runtime model. Every run records the imported Newton and MJWarp commits in its JSON artifact. The latest Hopper harness fix moves the deterministic start 0.05 rad inside the two upper joint limits; exact-limit starts had clean root/action gradients but bad joint-position VJPs and made SHAC checkpoint selection fragile.

What Is Not Fixed

PPO now works as an environment sanity check for all three locomotion tasks, and SHAC has clean stepping-stone results for Cheetah and Hopper. For Ant, the old visual failure was partly a harness bug: native no-squash actions were not clipped before torque mapping. After the clamp fix, the PPO positive control is upright and repeatable at 15.18 m with 0/5120 no-reset terminal worlds, 0 invalid worlds, and 0.945 minimum-up in the worst repeat. The current H=8 SHAC update can improve displacement to 15.39 m in the deterministic no-reset replay and stays terminal-free across five 1024-world repeats, but the repeated minimum-up dip shows it is not yet the best reliable Ant gait. Longer SHAC horizons with contact-surrogate adjoints are currently CPU-bound, and later H=8 steps can select a rare contact branch that falls despite better short-horizon reward. Hopper required two harness fixes: the default deterministic start is now 0.05 rad inside the two upper joint limits, and the selector uses a large fall gate so 0-fall checkpoints beat slightly faster late-fall checkpoints. Ant additionally needed the corrected potential-progress timestep, action clamping, IsaacLab-style bounded effort, and no-reset selection to avoid reporting reset-spliced reliability. The latest fixed-action checks explain the SHAC side of the pattern: reset-state one-step gradients are clean, but H=8/H=16 Ant rollouts enter grazing foot contacts where contact-position and orientation derivatives diverge from finite differences.

Current Ant Diagnosis

The bad-looking Ant PPO/SHAC videos were not caused by renderer overlays: every new clip is raw ViewerGL.get_frame(). The main harness bug was action magnitude. DiffRL and IsaacLab clamp actions before applying actuator effort; the Newton report runners previously trusted native no-squash policy outputs and could feed out-of-range torques into the Ant. After clamping, PPO becomes repeatable and visually plausible, while SHAC can make small progress but still has a long-horizon reliability problem. The next technical blocker is not a root-velocity indexing bug either; a unit-velocity probe confirmed qd[0:3] are linear root velocity and qd[3:6] are angular. The remaining failure mode is contact-rich Ant optimization: H=32 surrogate contact adjoints are currently too slow, H=16 strict anchored updates improve nominal reward but fail repeated audits with late falls, and H=8 can overfit a local contact branch that later dips or falls. A 256-world five-repeat selector found a faster H=8 candidate, but re-auditing that actor at 1024 worlds still produced 1 terminal world across five repeats. A valid tanh-wrapped 31 m SHAC actor also looked clean in a small 5 x 16-world audit, but the new 5 x 1024-world audit recorded 7 terminal worlds and inverted-up minima. A late-state warmup SHAC repair attempt kept the 31 m gait, but still selected 1-3 fall worlds through six epochs. The current headline therefore stays with the terminal-free clipped H=8 result despite its posture dip.

Ant Reliability Controls

The earlier Ant zero-fall claim came from reset-style evaluation and a shorter/default selector. The harness now has an uninterrupted no-reset selector, the IsaacLab-potential reward uses the full control timestep, and native no-squash actions are clamped before torque mapping. With those fixes, the clipped PPO anchor reaches 15.18 m in the 1024-world no-reset replay with 0 terminals, 0 invalids, minimum up 0.952, and minimum height 0.475 m. Five repeated 1024-world no-reset audits stay terminal-free with worst-repeat minimum up 0.945. Loading the same actor through the SHAC path gives the same behavior, which rules out a SHAC checkpoint-loader or render-state issue. A cautious H=8 SHAC update improves the selected deterministic replay to 15.39 m and stays terminal-free across five repeated audits, but one repeat dips to 0.485 minimum-up before recovery and the next epoch finds a rare fall. The remaining Ant problem is therefore not renderer overlays, reset splicing, action loader mismatch, or root velocity indexing. It is long-horizon optimization through repeated Ant contacts with a bounded-action contract. H=32 contact-surrogate SHAC currently runs too slowly to use as the main training loop, while H=8 is fast enough but too local to guarantee posture robustness. The latest strict H=16 probe selected epoch 5 at 15.31 m, but its five-repeat audit recorded 2 terminal worlds and minimum-up -0.91. A stricter H=8 repeated-selector probe found a 15.55 m training candidate under 256 worlds times five repeats, but the promoted actor recorded 1 terminal world under the 1024-world five-repeat audit. The new 31 m tanh-wrapped SHAC audit is even more direct: it records only 0 falls in a 5 x 16-world audit, then 7 terminal worlds in a 5 x 1024-world audit. These negative probes confirm that selection scale, not just nominal rollout quality, is the remaining Ant blocker.

Ant Fall Timing

Older late-fall no-reset replays recorded first Ant SHAC terminals around steps 430-770 depending on the stochastic reset batch, and corrected-default probes also fell late around steps 348-461. These were not reset splices or camera artifacts: failed worlds had torso heights below the termination threshold and flipped/upside-down up projections after long contact interaction. The current clipped H=8 SHAC run no longer terminates in the five repeated 1024-world audit, but its worst repeated minimum-up is 0.485, much lower than the PPO anchor's 0.945. That posture dip is the remaining warning sign. Future work should improve Ant clearance and contact robustness without reintroducing the old unbounded-torque behavior or collapsing into the standing policies found by earlier soft-height PPO probes.

Code Findings

The most important MJWarp fixes were not contact-specific. First, free-joint kinematics were recomputed once per branch, corrupting qpos gradients for floating roots. Second, dense mass assembly had no useful generated adjoint for the dense matrix path used by the solve. Third, RNE force accumulation needed explicit adjoints for cfrc_int, cinert, cdof, and related kinematic intermediates. Fourth, _advance had to isolate output qpos/qvel arrays under AD to avoid overwriting saved inputs. Fifth, Newton's free-joint force route writes to MJWarp xfrc_applied; the support.apply_ft map into qfrc_smooth needed an explicit VJP for free-root force controls. The latest Hopper free-fall drilldown showed the key cancellation bug: CPU MuJoCo and MJWarp both produce pose-independent free-fall acceleration, but AD still injected root-angle and joint-position gradients. Finite-difference decomposition showed the dense M VJP was correct; the residual came from leaving Warp auto-AD active through qfrc_bias = dot(cdof, cfrc) and the cfrc tree accumulation while also recording the custom RNE adjoint. The fix disables those auto-backward kernels and records an explicit qfrc_bias adjoint that routes cdof.grad and cfrc_total.grad exactly once. The latest Newton-side Hopper bug was an importer/exporter mismatch: MJCF can define multiple scalar root joints on one body with distinct joint pos anchors, while Newton merges them into one D6-style joint. SolverMuJoCo was exporting every expanded MuJoCo joint with the merged child transform position, and the runtime mjw_model.jnt_pos refresh repeated the same mistake. A new per-DOF mujoco:dof_jnt_pos attribute now preserves those anchors through import, export, and MJWarp data refresh.

SHAC Findings

The harness had its own bug: early terminal falls still bootstrapped from the critic. DiffRL sets the terminal value to zero for early termination. Matching that behavior, and making terminal fall reward a fixed negative value, removes the high-speed crash exploit. The new upright gate also rejects the rolled-over progress policy. The remaining failure is no longer a reset-state smooth-dynamics gradient bug: Hopper and Ant short-horizon state/action checks now pass, but SHAC training still trades progress against repeated contacts and active limits poorly. Ant H=8 fixed-action rollouts now isolate the gap to grazing foot contacts: local action derivatives are good at reset, then contact-position and orientation finite differences diverge once foot distances sit just inside the inclusion margin. Hopper with limits on is nonsmooth at reset because the thigh and leg joints start on their upper stops; reset noise is now clamped back inside finite limits, and the new inside-limit start-pose probe confirms this was a real harness bug. Earlier Gym-style reward and upright warm-start Hopper probes still became falling policies, but the inside-limit deterministic start plus 1024-world fall-gated selector gives a clean 13.65 m SHAC result. Cheetah remains the cleanest success case, and PPO verifies the faithful 16-substep Cheetah environment. Ant needed two environment fixes beyond the MJWarp adjoints: local Isaac-style observations/reward terms and an action-order option that can match either IsaacLab-style joint order or MuJoCo actuator order. A later report-runner bug was that the Isaac-style reward accepted --ant-height-weight but ignored it; the runners now support both height-shaped and no-height physical rewards. A later pass found that the claimed IsaacLab defaults were still inheriting DiffRL XML damping/friction/termination/limit-cost values. After correcting those defaults, PPO reaches 11.82 m with 0 no-reset terminals in an early full-horizon replay, and low-lr deterministic SHAC improves fast shaped Ant displacement to 23.19 m but still has rare terminals. The stricter no-reset evaluator changed the conclusion, and the latest harness fix changed it again: native no-squash actions must be clamped before force assignment. PPO actors that declare action_squash=none are no longer silently tanh-wrapped by shared evaluation, and they are no longer allowed to feed unbounded torque commands into Newton. Under that bounded contract, the current Ant PPO sanity check is 15.18 m with 0/5120 no-reset terminal worlds. The same actor loaded through SHAC replays at 15.17 m, and a cautious H=8 SHAC update improves deterministic displacement to 15.39 m while staying terminal-free across five repeated no-reset audits. The remaining blocker is posture robustness: one repeated SHAC rollout dips to 0.485 minimum-up, and the next H=8 epoch finds a rare falling branch. The newest SHAC instrumentation records selection minima and posture shortfalls in every history row. Progress-2 SHAC continuation did not beat the selected actor: safe updates stayed below 14.79 m, while updates that chased more progress first lost uprightness, with min-up falling to roughly 0.72-0.84; torso height was not the limiting constraint. For native NV Ant, the no-reset single deterministic videos now look physically continuous, but large identical-world replays expose robustness failures because contact dynamics amplify tiny per-world floating-point differences by mid-rollout. The 500k-penalty NV SHAC continuation reduced those failures but still ended at 14 falls/3 invalids, so NV remains a diagnostic asset rather than the headline result. The remaining problem is qualitative and algorithmic: Hopper SHAC needed the start-pose active-set fix and a much stronger fall gate before it became reliable, while Ant SHAC now needs a long-horizon update that improves the bounded-action PPO gait without exploiting a fragile contact branch. Contact finite differences still degrade once Ant feet sit on grazing active-set boundaries. The missing piece is now a curriculum/objective that preserves more natural height and heading while increasing progress, plus a contact adjoint or smoothing strategy that remains useful across long horizons and active-set boundaries. The current no-reset matrix is Cheetah SHAC at 10.41 m, Hopper SHAC at 13.65 m, and Ant SHAC at 15.39 m under the clipped-action contract; the open target is improving the Ant gait beyond low-clearance crawling while preserving the zero-terminal repeated audits. It no longer looks like a single RNE mass/bias cancellation bug.
