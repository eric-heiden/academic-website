Cartpole Fix

The first cartpole run loaded the DiffRL URDF directly into a Y-up Newton model. DiffRL actually applies a -pi/2 rotation about X before setting the pole joint to -pi. Without that transform, gravity and the pole axis were mismatched, producing the sideways-looking behavior. The Newton harness now applies the same transform.

Ant Fix

The ant MJCF import was missing an explicit ground plane, so both contact backends initially let the ant fall through the world. The ant builder now uses DiffRL's Y-up transform, rest pose, contact material, previous-action observation, early termination, and a Y-up ground plane before SolverMuJoCo is constructed.

Implementation Notes

Newton's SolverMuJoCo uses the MJWarp differentiability branch with opt-in gradient-enabled data fields. The harness wraps one Newton/MJWarp step in a PyTorch autograd function: forward runs the solver normally, backward replays the step under a Warp tape and returns MJWarp adjoints to PyTorch.

Status

Cartpole is physically plausible and stabilizes. Ant now has correct ground contact and trains with both MuJoCo contacts and Newton differentiable contacts. Newton contacts produced the strongest return in this pass, but the policy can still exploit hopping/high-height motions, so the report separates speed-oriented return from clean-rollout diagnostics.
