What Worked

The MJWarp PR exposes gradient-enabled data fields that can be enabled from Newton. Cartpole produces nonzero actor gradients and improves from the down equilibrium to a swing-up behavior over 100 differentiable policy updates.

What Did Not Yet Work

Ant contact dynamics are differentiable enough to run backward and improve the first few short-horizon updates, but this actor-only bridge is not stable over a longer 3 second rollout. A full SHAC critic, better reset handling, and contact-aware constraints are the next required pieces.

Implementation Notes

Newton's SolverMuJoCo now has opt-in requires_grad support and public enable_grad()/disable_grad() helpers. The report harness wraps one Newton/MJWarp step in a custom PyTorch autograd function: forward runs Newton normally, backward replays the same step under a Warp tape and returns the MJWarp adjoints to PyTorch.

Scope

This is not yet the complete DiffRL SHAC trainer. It uses the DiffRL deterministic actor model and a short-horizon differentiable objective to test whether the MJWarp differentiability branch can train through Newton. The critic update and replay buffer from full SHAC are intentionally left for the next pass.

Reproduction

uv run --project /home/horde/repos/newton-shac --extra dev --extra torch-cu12 \
  --with imageio --with imageio-ffmpeg --with pillow \
  python /home/horde/repos/academic-website-reports/shac/run_newton_shac.py \
  --env cartpole --num-envs 64 --epochs 100 --horizon 48 --eval-horizon 240 \
  --force-scale 750 --reset-noise 0.35 --lr 0.003 --grad-clip 25 \
  --render-video --video-num-envs 1

uv run --project /home/horde/repos/newton-shac --extra dev --extra torch-cu12 \
  --with imageio --with imageio-ffmpeg --with pillow \
  python /home/horde/repos/academic-website-reports/shac/run_newton_shac.py \
  --env ant --num-envs 8 --epochs 25 --horizon 12 --eval-horizon 180 \
  --force-scale 80 --reset-noise 0.0 --lr 0.0005 --grad-clip 10 \
  --render-video --video-num-envs 1
