Dynamics Fix

The first cartpole run loaded the DiffRL URDF directly into a Y-up Newton model. DiffRL actually applies a -pi/2 rotation about X before setting the pole joint to -pi. Without that transform, gravity and the pole axis were mismatched, producing the sideways-looking behavior. The Newton harness now applies the same transform.

Training Fix

The earlier harness reset every epoch and optimized only a truncated actor objective. The rerun keeps persistent 240-step episodes, samples the stochastic actor during training, normalizes observations, and trains a TD-lambda critic target like DiffRL SHAC. The policy now swings up and finishes upright near the rail center.

Implementation Notes

Newton's SolverMuJoCo uses the MJWarp differentiability branch with opt-in gradient-enabled data fields. The harness wraps one Newton/MJWarp step in a PyTorch autograd function: forward runs the solver normally, backward replays the step under a Warp tape and returns MJWarp adjoints to PyTorch.

Status

Cartpole is now physically plausible and trains to an upright stabilizing policy. Ant remains deferred for the next pass; it needs the same full SHAC treatment plus contact-specific validation before its published numbers should be trusted.

Reproduction

uv run --project /home/horde/repos/newton-shac --extra dev --extra torch-cu12 \
  --with imageio --with imageio-ffmpeg \
  python /home/horde/repos/academic-website-reports/shac/run_newton_shac.py \
  --env cartpole --num-envs 64 --epochs 200 --horizon 32 \
  --eval-horizon 240 --selection-horizon 240 --episode-length 240 \
  --force-scale 1000 --stochastic-init --stochastic-actor \
  --use-critic --obs-rms --critic-method td-lambda --td-lambda 0.95 \
  --lr 0.01 --critic-lr 0.001 --lr-schedule linear \
  --adam-beta1 0.7 --adam-beta2 0.95 --grad-clip 1 \
  --critic-iterations 16 --critic-batch-size 512 \
  --target-critic-alpha 0.2 --render-video --video-num-envs 1
