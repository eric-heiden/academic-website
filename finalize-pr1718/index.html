Newton ModelBuilder.finalize() PR 1718 Benchmarks

RL-style USD import workloads: load one MuJoCo-menagerie USD asset, register MuJoCo custom attributes, replicate it across 10 to 16,384 worlds, and measure only ModelBuilder.finalize(device="cuda:0"). The old PR branch was 644 commits behind current main and did not rebase cleanly, so this report measures current main plus targeted runtime patches representing the optimization ideas.

What Was Measured

Finalize wall time, host RSS delta/peak delta during finalize, GPU memory delta, model sizes, custom-attribute slots, and contact-pair counts. USD load and replication are recorded but excluded from the main finalize plots.

Important Caveat

The array-backed builder result is a pre-finalize storage-layout proxy. It is not a clean port of the stale PR's MutableSequence implementation, which is much more invasive.

Recommendation

Prioritize the wp.full custom-attribute default path first because it is the broadest low-intrusion speed win at 16k worlds. Add the small geo_id geometry-dedup change next for mesh-heavy assets, but test the combination rather than assuming the speedups stack. Do not port the array-backed builder container layer wholesale from PR 1718; despite memory wins in the proxy, the real implementation is high-intrusion and should be redesigned only after re-profiling the smaller fixes.
