What The Current Methods Mean

Compact collision-filter blocks

High

Store replicated shape-collision filter pairs as one local template plus one shape offset per copied world, and use that compact metadata to build contact pairs. This avoids creating and then canonicalizing tens of millions of Python tuples for large replicated robots.

Implementation surface: newton/_src/sim/builder.py and ModelBuilder.shape_collision_filter_pairs API behavior

add_builder(): Direct add_builder()/replicate() optimization for filtered USD robots, and a direct finalize() optimization because the giant filter set is no longer materialized.

local_filter_pairs = tuple(source.shape_collision_filter_pairs)
builder.shape_collision_filter_pairs.extend_offset(local_filter_pairs, start_shape_idx)

if filter_blocks_cover_all_pairs:
    model.shape_collision_filter_pairs = LazyFilterView(builder.shape_collision_filter_pairs)
    find_shape_contact_pairs_from_filter_blocks(model)

Custom attr wp.full

Low-Medium

When a custom attribute has no explicit values, allocate the Warp array directly with wp.full(count, default). This avoids building a huge Python list of repeated defaults before converting it.

Implementation surface: newton/_src/sim/builder.py

add_builder(): No direct effect on add_builder(); it changes how finalize() materializes Model/State/Control custom attributes.

if self.values is None or len(self.values) == 0:
    if self.dtype is str:
        return [self.default] * count
    return wp.full(
        count,
        self.default,
        dtype=self.dtype,
        requires_grad=requires_grad,
        device=device,
    )

Mesh SHA hash

Low

Changes the first-time mesh hash from Python tuple hashing of every vertex/index to a SHA-256 hash over the mesh buffers. This targets large mesh hashing overhead.

Implementation surface: newton/_src/geometry/types.py

add_builder(): No direct effect on add_builder(); it only changes hash calls made later by finalize().

def __hash__(self):
    cached = getattr(self, "_cached_hash", None)
    if cached is None:
        h = hashlib.sha256(self._vertices.tobytes())
        h.update(self._indices.tobytes())
        cached = int.from_bytes(h.digest()[:8], "big")
        self._cached_hash = cached
    return cached

Geometry id dedup

Low

Inside finalize(), use the geometry object's identity as the deduplication key. Replicated worlds reuse the same mesh objects, so identity avoids repeatedly hashing equivalent geometry.

Implementation surface: newton/_src/sim/builder.py

add_builder(): No direct effect on add_builder(); it changes finalize()'s geometry dedup lookup.

for geo in self.shape_source:
    geo_hash = id(geo)
    if geo_hash not in finalized_geos:
        finalized_geos[geo_hash] = finalize_geometry(geo)

Array proxy / compact_finalize_storage()

Medium

Opt-in pre-finalize compaction for selected builder fields. The helper converts list-heavy finalize inputs to array.array or NumPy storage before the measured finalize() call, while leaving add_builder() semantics unchanged.

Implementation surface: newton/_src/sim/builder.py

add_builder(): No direct effect on add_builder(); it is called after replication and before finalize().

builder.compact_finalize_storage()
model = builder.finalize(device=device)

Recommendation

Land first: the default branch changes are now the best low-risk bundle: compact filter blocks drive the add_builder() win, while wp.full, cached mesh hashing, and identity geometry dedup reduce finalize() overhead without broad API changes.

Next decision: the optional compact_finalize_storage() path is the clearest remaining finalize win. It should stay opt-in until mutable-builder semantics and downstream extension points are reviewed, but the G1 16k focused rerun shows it is worth productionizing carefully.
