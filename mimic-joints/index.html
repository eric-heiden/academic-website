Newton API Prototype

Mimics Are Joints

A clear-cut implementation report for moving URDF and USD mimic relationships into zero-DOF JointType.MIMIC followers, with real ViewerGL videos and solver timing instead of schematic captures.

Implementation

URDF <mimic>, USD NewtonMimicAPI, and USD PhysxMimicJointAPI import as joint metadata. FK and IK consume the follower inline. MuJoCo lowers each Newton MIMIC joint to the synthetic scalar coordinate and mjEQ_JOINT row that MuJoCo needs internally; that lowering is not a second Newton model representation.

This branch also adds solver-side adoption work: Featherstone refreshes MIMIC follower transforms and velocities, and XPBD explicitly skips zero-DOF MIMIC followers in the joint-force kernel.

ViewerGL Captures

These are MP4 captures rendered from real imported assets using ViewerGL.get_frame() in headless EGL mode. No schematic captures are used in this report.

Verdict

Mimics are joints. Importers attach mimic metadata to joints, FK/IK consume it directly, and solvers either consume JointType.MIMIC natively or lower it privately. The remaining branch gap is VBD rigid MIMIC support, and it is visible as an unsupported benchmark row rather than hidden by a skipped test or schematic capture.
